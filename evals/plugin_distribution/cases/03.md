# 03. 작업 폴더 초기화와 기존 지침 보존

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `claude_empty` / `codex_empty` / `claude_existing` / `codex_existing` / `reinitialize` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: workspace_empty (fixtures.json의 실제 파일로 제공)

variant에 맞는 새 시험 작업 폴더를 초기화하세요. 기존 지침이 있는 variant는 표식 KEEP_EXISTING을 보존하세요. 재초기화는 같은 위치로 반복하세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
