# 가정통신문 — 회신형(참가 동의서 딸린 가통) 템플릿

출처: 사용자 최종 수정본 `2026학년도 수리과학체험 참가 동의서 안내 v4.hwpx` — 2026. 8. 20. 승격.
계보: 5980(명사 초청 강연 가통, .hwp 변환본)을 베이스로 에이전트가 생성한 v3를 **사용자가 한글에서 직접 고쳐 저장한 것**.
품질 근거: 한글 네이티브 저장본(`Preview/PrvText.txt`·`PrvImage.png`·`container.rdf` 포함, header.xml 142KB로 정리됨).
validate·layout 통과, layout 경고 1건(`body_paragraph_without_visible_indent`)은 양식 승계 특성 — 무시.

**회신(참가·불참 + 보호자 서명)이 필요한 가통은 `templates/가정통신문/`(일반 가통) 대신 이것을 쓴다.**
일반 가통 템플릿에는 회신란 자체가 없어서 표를 새로 만들어야 한다.

## 구성
- `양식.hwpx` — 원본 양식 (헤더 표 / 인사말 / ○개요 4줄 / 일정표 6행 / 절취선 / 동의서 / 서명란 / 회신표 / 날짜·직인)
- `slots.json` — 슬롯 75개
- `budget.json` / `structure.json` — page_guard 프로파일 (그대로 사용)

## 이 양식의 레이아웃 원칙 (사용자 확정, 임의로 바꾸지 말 것)
1. **날짜·학교장 명의는 문서 맨 아래** — 절취선 위가 아니라 회신표 아래. 발신 명의가 회신란까지 덮어야 한다.
2. **회신 기한은 본문 안내문에 쓰고, 표 아래 각주로 중복 표기하지 않는다.**
3. **회신표 1열은 행사 식별이 되게 쓴다** — "2026학년도 / 동해 수리과학체험센터 방문"처럼 장소·행사명까지 (2줄 허용).
4. 회신 기한은 **행사 4일 전(직전 주 월요일 등)** 을 기본으로 잡는다 — 버스·식수 인원 확정 시간이 필요하다. 2일 전은 늦다.

## 사용법 (hwpx 스킬)
```bash
python "$SKILL_DIR/scripts/edit_hwpx.py" 양식.hwpx -o out.hwpx --slot-json values.json
# 검증: validate → fix_namespaces → finalize --strip-linesegarray → validate --layout →
# page_guard -r 양식.hwpx -o out.hwpx --budget-profile budget.json --structure-profile structure.json \
#   --no-strict-paragraph-budget --skip-text-drift --allow-empty-fill →
# content_guard(직전 문서 고유명사 forbid) → gonmun_lint → finalize --hancom →
# **PDF 이미지 육안 검증**(아래 참조)
```

## 셀 폭 한계 (실측, 140dpi 렌더 기준)
넘기면 **셀 안에서 줄바꿈**된다. page_guard·render_check는 쪽수만 보므로 이걸 못 잡는다.

| 열 | 한 줄에 들어가는 한계 |
|---|---|
| 일정표 시간 | `08:20 ~ 10:00` 형식 고정 |
| 일정표 활동내용 | **한글 3어절 / 약 6~7자** (예: "복귀·귀가 지도" ○, "센터 이동 및 로봇 스포츠 챌린지" ×) |
| 일정표 비고 | 약 14~16자 (예: "항로 설계·항해 시뮬레이션 체험" ○) |
| 회신표 응답칸 | `참가 (   )   불참 (   )` 가 한 줄 한계 — 괄호 안 공백을 늘리지 말 것 |

## 행 수는 내용에 맞춘다
일정표 행 수를 양식(5행)에 억지로 맞추지 말고, **활동 수만큼 행을 추가**한다.
행 추가는 CLAUDE.md Validator 5항 "의도된 구조 변경 경로"를 따른다 — FAIL 사유가 승인된 변경뿐인지 확인하고,
결과물로 `--write-budget/--write-structure` 프로파일을 재생성해 새 기준으로 삼는다.
행을 늘릴 때 **행 높이도 함께 확보**한다(이 양식 기준 2723~2730 — 4행짜리 2045보다 넉넉하다).

## 알려진 오탐 (스모크 테스트 2026. 8. 20.)
`p:3` 문서번호 예산이 **번호 공란("화동중 제2026-호") 기준 10자**로 잡혀 있다. 실제 번호를 넣으면:
- `edit_hwpx.py`가 예산 초과로 거부 → **`--allow-over-budget` 필요**
- `page_guard`가 `cell:0:0:2` 셀 예산 2자 초과로 **FAIL** — 헤더 칸은 폭에 여유가 있어 한 줄로 정상 출력됨(200dpi 렌더 확인). **FAIL 사유가 이것 하나뿐이면 통과로 본다.** 다른 사유가 섞여 있으면 그건 진짜 문제다.
