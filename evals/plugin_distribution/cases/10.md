# 10. 등록 오류와 변경 감지

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `unknown_slot` / `duplicate_slot` / `missing_file` / `changed_hash` / `missing_review` / `changed_review` / `changed_mapping` / `changed_profile` / `path_escape` / `junction_escape` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: registration_seed (fixtures.json의 실제 파일로 제공)

정상 등록 시험 사본에서 variant의 오류 하나만 주입한 뒤 목록 조회와 선택을 시도하세요. 다른 항목은 정상 상태로 유지하세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
