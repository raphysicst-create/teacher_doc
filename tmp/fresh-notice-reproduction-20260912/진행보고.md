# 독립 가정통신문 재작성 시험

- 프로젝트: Hwp_doc.
- 요청: 기존 확정 내용으로 2026학년도 2학기 1회고사 안내 가정통신문 본체 1건 재작성.
- 격리: 지침·스킬·scripts·knowledge와 업무지침 MCP만 읽었다. 기존 output 산출물, 다른 tmp 작업물, 과거 세션·메모리 및 evals 기대 판단을 보지 않았다.
- 환경·파일 SHA256·실제 생성 범위 확인: `environment-and-sources.json`. 정본과 `.agents` Junction의 스킬 본문 해시는 동일하다.
- 사용자의 재작성 시험 요청을 생성 권한으로 해석했다는 부모 확인이 있다. 이는 새로운 사용자 초안 승인 발언이 아니다. 실제 사용자 발언과 부모의 범위 확인을 구별 기록했고 새 검토 점수·동의를 기록하지 않았다.

5. fusion_timetable.py로 10월 27일 화요일·28일 수요일·29일 목요일·11월 2일 월요일을 기계 확인했다. 특별 고사시간표는 사용자의 값을 사용했다. 도구의 평상시 교과값은 고사 과목으로 사용하지 않았다.

## 보호 훅 실측 실패

첫 명령은 양식→tmp 기준 사본 복사 및 후속 검증을 연결한 명령이었다. 도구 실행 전 차단되어 후속 명령도 실행되지 않았다.

```powershell
Copy-Item -LiteralPath knowledge/templates/가정통신문-고사안내/양식.hwpx -Destination tmp/fresh-notice-reproduction-20260912/reference.hwpx; & 'C:/Users/22/AppData/Local/Programs/Python/Python312/python.exe' -X utf8 .claude/skills/hwpx/scripts/fix_namespaces.py tmp/fresh-notice-reproduction-20260912/reference.hwpx; & 'C:/Users/22/AppData/Local/Programs/Python/Python312/python.exe' -X utf8 .claude/skills/hwpx/scripts/finalize_hwpx.py tmp/fresh-notice-reproduction-20260912/reference.hwpx --strip-linesegarray --layout; & 'C:/Users/22/AppData/Local/Programs/Python/Python312/python.exe' -X utf8 .claude/skills/hwpx/scripts/page_guard.py --reference tmp/fresh-notice-reproduction-20260912/reference.hwpx --write-budget tmp/fresh-notice-reproduction-20260912/budget.json --write-structure tmp/fresh-notice-reproduction-20260912/structure.json
```

둘째는 절대경로 단일 복사 명령으로 좁혔지만 동일 차단됐다.

```powershell
Copy-Item -LiteralPath 'C:/Users/22/Desktop/maintain/Hwp_doc/knowledge/templates/가정통신문-고사안내/양식.hwpx' -Destination 'C:/Users/22/Desktop/maintain/Hwp_doc/tmp/fresh-notice-reproduction-20260912/reference.hwpx'
```

차단 사유: `Command blocked by PreToolUse hook: 보호 폴더 직접 쓰기: 정적 명령으로 안전한 대상 구분 불가.`

동일 단계 두 번 실패로 자동 시도를 중지하고 부모에게 알렸다. 부모가 훅 오탐 수정 및 회귀검사 27건 통과를 보고하고 수정 후 1회 재개를 지시했다. 수정 후 동일한 단일 복사 명령을 1회 호출했으나 같은 차단 사유가 재현되어 다시 멈췄다. 수정이 해당 도구 호스트에 실제 적용되었는지는 미확인이다.

이 실패는 원본을 수정하려다 막힌 사례가 아니라, 원본을 읽고 현재 프로젝트 tmp의 새 파일로 복사하려는 작업에서 발생했다. 기준 사본 준비 실패를 양식 생성·검증 성공으로 표시하지 않았다.

## 입력 예산 검토

`read-only-budget-inspection.json`은 현재 원본에서 읽기만 수행한 예산 검사 자료다. finalize 후 기준 프로파일로 사용할 수 있는 산출물이 아니므로 완료 검증 기준으로 쓰지 않는다.

- 슬롯 추출의 정상수업 4자, 날짜 8자 등은 기존 문자열 길이를 넘지만 실제 셀 폭 기반 예산에서는 각각 14자·10자로 수용 가능한 것으로 계산된다. 그래도 재패키징 베이스 및 원본 슬롯 예산 초과이므로 PDF→PNG 육안 검증이 필요하다.
- 배부일 `2026. 10. 14.`은 공백 제외 11자로 기존 문단 예산 10자를 넘는다. 날짜를 축약·변조할 수 없으므로 실제 미검증 사본의 PDF→PNG 확인 후 판단해야 한다. 검증하지 않고 `--verified-by-render`를 붙이지 않았다.
- 초안의 일정·이의신청 문단도 각각 35/33, 36/34로 사전 예산보다 길다. 회차 반복 표현을 덜 수 있지만 아직 편집·렌더한 결과가 아니다.
