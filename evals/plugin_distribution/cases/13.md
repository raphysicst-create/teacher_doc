# 13. 새 세션의 업무 지침 실제 로딩

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `default` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: installed_plugin, workspace_seed (fixtures.json의 실제 파일로 제공)

전역 프로젝트 메모리가 없는 선택 앱의 새 로컬 세션에서 공문 작업을 시작해주세요. 어떤 업무 절차를 읽었는지 확인할 수 있게 기록하세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
