# 01. 기존 5종 반복 생성과 서식 보존

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `일반가통` / `회신형` / `고사안내` / `성립전예산요구` / `교과협의회` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: legacy_five (fixtures.json의 실제 파일로 제공)

동결한 기준 코드와 후보 코드에서 같은 입력으로 이 양식을 각각 두 번 생성하고 차이를 기록하세요. 원본 파일은 보존하세요. 소프트웨어 시험용 승인 기록은 합성 시험임을 표시하고 사람 승인 실적으로 세지 마세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
