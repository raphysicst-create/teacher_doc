# teacher_doc 처음 시작하기

## 준비할 것

- 파일을 읽고 명령을 실행할 수 있는 Codex 환경
- 인터넷 연결과 프로그램 설치가 허용된 환경. Python 3.12는 없으면 동의 후 전용 폴더에 준비합니다
- 플러그인 코드와 분리된 문서 작업 폴더

한글 프로그램과 실제 학교 자료는 첫 연습에 필요하지 않습니다. 실제 공문의 한글 열기·인쇄 모양까지 확인하려면 Windows에 설치된 한글과 동작하는 자동화 환경이 필요합니다.

## 1. 링크를 붙이고 부탁하기

Codex 대화에 다음을 붙여 넣으세요.

> https://github.com/raphysicst-create/teacher_doc
>
> 이 플러그인을 Python 포함 설치해줘. Python 3.12가 없으면 공식 Astral uv와 CPython 배포본을 teacher_doc 전용 폴더에 받아도 돼. 저장소 전체를 설치하고 내 자료와 분리된 작업 폴더에서 기본 XML 점검과 첫 연습 문서 생성까지 해줘. 파일과 점검 결과를 보여줘.

특정 컴퓨터나 폴더를 쓰고 싶으면 함께 알려주세요. 예: “내 Windows 컴퓨터의 문서 폴더에 작업 폴더를 만들어줘.” 에이전트가 그 환경에 접근할 수 없으면 연결이나 실행 권한이 필요한 단계에서 안내합니다.

에이전트가 진행할 일은 다음과 같습니다.

1. 전체 저장소를 지속 보관할 설치 위치에 받거나, 지원되는 플러그인 마켓플레이스에서 설치합니다
2. 기존 Python 3.12가 있으면 재사용하고, 없으면 위 동의에 따라 앱 전용 Python과 가상환경을 만듭니다
3. 코드 폴더 밖의 작업 폴더를 준비합니다. 기존 설정이 있으면 보존합니다
4. 기본 XML 환경을 점검합니다
5. 합성 연습 양식에 내용을 채운 HWPX와 검사 보고서를 생성합니다
6. 실제 결과 경로와 확인하지 못한 부분을 알려줍니다

Python 다운로드는 위 문장처럼 명확히 승인한 경우에만 진행합니다. 단순 설치 요청이라면 한 번 동의를 구하고, 거절하면 멈춥니다. 프로그램 구매, 한글 설치, 보안모듈 등록, 훅이나 보안 설정 변경을 한꺼번에 자동 처리하지 않습니다.

## 2. 연습 결과 보기

연습 파일은 **작업 폴더의 `output/teacher-doc-practice/`**에 있습니다. 연습 결과는 `first-document.hwpx`, 원본 합성 양식은 `template.hwpx`, 검사 보고서는 `practice-report.json`입니다. 설치 폴더나 플러그인 캐시에 학교 자료를 넣지 않습니다.

에이전트에게 이렇게 물을 수 있습니다.

> 방금 만든 연습 HWPX와 검사 보고서를 보여줘. 어떤 검사까지 성공했고 무엇은 아직 확인하지 못했는지 알려줘.

연습 파일은 개인정보가 없는 합성 예제입니다. 학교 양식으로 등록되거나 승인된 공문이 아닙니다. 실제 학교 양식·학생 정보·예산 자료를 제공하지 않아도 만들어 볼 수 있습니다.

## 3. XML 모드와 전체 모드 이해하기

**XML 모드**는 HWPX 파일 안의 구조를 읽고 내용을 채우는 경로를 점검합니다. Windows·macOS·Linux에서 시작할 수 있으며 한글이 없어도 진행할 수 있습니다.

**전체 모드**는 Windows에 설치된 한글의 COM 자동화 환경을 추가로 확인합니다. 한글 설치 여부, 보안모듈과 현재 실행 환경에 따라 실패하거나 확인하지 못할 수 있습니다. 한글 COM이 가능해도 각 문서의 필요한 PDF/PNG 검사와 실제 육안 판독은 따로 해야 합니다.

XML 검사 성공은 한글에서의 줄바꿈·표 잘림·쪽수·인쇄 모양이 정상이라는 보증이 아닙니다. 전체 검사가 막히면 그 상태를 그대로 남기고 Windows 환경에서 필요한 검사를 이어갑니다.

Windows에서 한글을 사용 중이라면 이렇게 요청하세요.

> 설치된 한글까지 확인해줘. 전체 모드 점검 결과를 보고, 별도 설치나 보안 설정 변경이 필요하면 먼저 설명해줘.

## 4. 실제 학교 양식으로 시작하기

연습 뒤에는 사용할 원본 양식과 바꿀 내용을 에이전트에게 알려주세요.

> 이 HWPX 양식을 원본 그대로 보존하면서 새 문서를 만들고 싶어. 먼저 양식과 내용을 읽고 필요한 정보를 알려줘. 초안을 보여준 다음 내 확인을 받고 진행해줘.

실제 작업은 기존 업무 절차를 따릅니다.

- 원본 양식을 읽고 보존할 표·상자·제목·명의 위치를 확인합니다
- 필요한 원문과 학교별 정보를 확인하고 초안을 보여줍니다
- 사람이 초안을 확인한 뒤 새 HWPX 사본을 만듭니다
- 구조·내용·한글 열기·필요한 렌더를 검증하고 미확인 사항을 남깁니다
- 사람이 최종 문서를 검토하고 발송합니다

학교 양식 등록, 초안 승인, 육안 판독 기록은 실제 확인 없이 만들지 않습니다. 발송 전 한글로 열어 확인해주세요.

## 설치가 잘 안 될 때

### “플러그인 검색창에서 주소를 찾을 수 없어요”

일반 대화에 주소를 붙여 설치를 부탁하는 것과 플러그인 검색창의 검색은 다릅니다. 앱·버전·계정·조직 정책마다 GitHub 가져오기 화면이 다를 수 있습니다. 위의 설치 부탁 문장을 일반 Codex 대화에 붙여 주세요. 에이전트가 지원되는 마켓플레이스 추가 또는 전체 저장소 설치 경로를 확인합니다.

### “플러그인을 추가했는데 Python이 없대요”

플러그인 파일 설치와 Python 환경 준비는 별도입니다. 다음과 같이 요청하세요.

> teacher_doc의 실제 설치 폴더에서 설치 안내를 읽고 Python 포함 설치를 이어서 해줘. Python 3.12가 없으면 공식 Astral 배포본을 전용 폴더에 받아도 돼.

앱 전용 자동 설치는 [공식 Astral 배포본과 고정 해시](PYTHON-RUNTIME.md)를 사용합니다. 임의 다운로드 사이트는 사용하지 않습니다.

### “hwpx 스킬은 있는데 scripts 파일이 없어요”

스킬 폴더만 설치된 상태일 수 있습니다. `teacher_doc` 저장소 전체가 필요합니다. 에이전트에게 전체 패키지 설치와 실제 설치 경로 점검을 요청하세요. 기존 작업 자료는 지우지 않습니다.

### “한글이 없거나 Mac/Linux를 사용해요”

XML 모드의 설치·연습은 진행할 수 있습니다. 한글 COM·PDF 내보내기·최종 인쇄 모양 확인은 미확인으로 남습니다. XML 검사를 통과했다고 실제 공문을 곧바로 발송하지 않습니다.

### “한글이 있는데 전체 점검은 실패해요”

설치된 한글, 보안모듈, Windows 사용자 세션이나 제한된 실행 환경의 차이일 수 있습니다. 에이전트에게 정확한 오류와 단계 확인을 요청하세요. 관리자 권한이나 실행 정책을 무작정 바꾸지 않습니다.

### “다운로드나 패키지 설치가 중간에 멈췄어요”

같은 작업 폴더와 PC 데이터 위치로 이어서 시도할 수 있습니다. 에이전트에게 실패한 단계와 오류를 확인하고 기존 설정을 보존한 채 재실행하도록 요청하세요. 네트워크나 조직 정책 차단이면 필요한 허용만 별도로 확인합니다. 보안 검사를 꺼서 해결하지 않습니다.

### “다시 실행하면 내 문서가 사라지나요?”

설치 코드는 문서 작업 폴더와 분리합니다. 기존 설정과 자료를 보존하며, 충돌이나 손상된 설정은 덮어쓰기 전에 멈추고 확인합니다. 업데이트나 앱 플러그인 제거 때도 작업 폴더를 함께 지우지 마세요.

## 에이전트용 실행 참고

이 부분은 설치를 진행하는 에이전트의 참고입니다. 사용자가 직접 실행할 필요는 없습니다. 상세 순서는 [설치 스킬](../skills/teacher-doc-setup/SKILL.md)을 따릅니다.

```sh
# 지원되는 CLI에서 전체 마켓플레이스 추가 및 플러그인 설치
codex plugin marketplace add https://github.com/raphysicst-create/teacher_doc.git
codex plugin add teacher_doc@teacher-doc-local --json
codex plugin list --json

# macOS/Linux, Python 포함 설치에 동의한 경우
bash scripts/bootstrap.sh --workspace "/코드/밖/작업 폴더" --data-dir "/코드/밖/PC 데이터" --allow-python-install
```

Windows에서는 `& "$pluginRoot/scripts/bootstrap.ps1" -Workspace $teacherWorkspace -DataDir $pcData -AllowPythonInstall`을 사용합니다. 동의가 없으면 동의 플래그를 빼고 실행합니다.

선택 사항은 `--data-dir <경로>`, `--school-data`, `--visual`, `--mode full`입니다. 앱·스킬 지정은 `--app codex|claude`, `--skill-name <앱에서 확인한 이름>`으로 전달할 수 있습니다. 사용자 지정 데이터 경로는 이후에도 `HWPDOC_PC_DATA`에 동일하게 지정하고, 설치 결과의 `python`에 기록된 전용 Python을 사용합니다. 설치 요약은 작업 폴더의 `.hwpdoc/onboarding.json`, 최근 환경 점검은 `.hwpdoc/doctor.json`에 남습니다.

설치 후 다시 점검하거나 연습하려면 전용 Python으로 실행합니다.

```sh
python -X utf8 scripts/teacher_doc.py --workspace "/작업 폴더" doctor --mode xml
python -X utf8 scripts/teacher_doc.py --workspace "/작업 폴더" first-doc
# Windows의 한글 환경은 별도로 확인
python -X utf8 scripts/teacher_doc.py --workspace "/작업 폴더" doctor --mode full
```

플러그인 파일 설치, 앱 목록 노출, 실제 스킬 로딩, XML 연습, Windows COM, 문서별 렌더 검토를 각각 보고합니다. [기존 배포 문서](../distribution/README.md)는 과거 개발·배포 검토 기록으로, 공개 패키지에 없는 명령은 최초 설치에 사용하지 않습니다.
