# 07. 기존 작업 기록과 승인 해시 호환

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `legacy_absolute` / `portable_record` / `changed_source` / `changed_manifest` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: job_seed (fixtures.json의 실제 파일로 제공)

기존 형식 작업 기록과 새 작업 기록을 읽으세요. variant에 따라 시험 사본의 원문 또는 승인 입력만 변경해 상태를 다시 확인하세요. 사용자의 새 승인을 만들어 넣지 마세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
