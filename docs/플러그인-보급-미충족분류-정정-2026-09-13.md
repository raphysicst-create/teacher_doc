# 미충족 66건 분류 정정

기존 보고서와 실행 기록은 그대로 보존한다. 66건은 발견된 결함 수가 아니라 시험 조건·근거의 미충족으로 분류했던 평가 행 수다.

| 수정 대상 | 기존 | 정정 | 이유 |
|---|---|---|---|
| 16--claude--no_marker | 미충족 | 미실행 | 공문 표시 없는 cwd의 별도 앱 시험을 실행하지 않았으며, 실행 불가능한 선행 조건은 입증하지 않음 |
| 16--codex--no_marker | 미충족 | 미실행 | 위와 동일 |
| 30--teacher_selected--default | 미충족 | 범위 제외 | 동료 교사 PC 최초 사용은 사용자가 제외한 외부 컴퓨터 시험에 해당 |

따라서 현재 115행의 상태는 **동작 확인 32 / 부분 확인 9 / 미충족 63 / 미실행 2 / 제외 9**다. 새 시험 통과 또는 독립 평가 점수 변경은 없다.

미충족 63행의 구성:

| 구분 | 건수 | 필요한 것 |
|---|---:|---|
| 양식·업무·변환 시험자료 | 34 | 새 양식 원본과 판독, 승인본 계보, 회신형 표·구조 비교, 셀 예산 초과 렌더, 사용 가능한 HWP 변환·재패키징 사본 |
| Claude MCP 실제 호출 | 2 | kordoc 연결 후 patch/fill 실제 호출·차단 증거 |
| COM·렌더 부재 조건 | 2 | 현재 설치를 제거하지 않는 격리 부재 환경. 모의 오류 시험은 이미 있으나 실환경 인수와 구분 |
| W2 문안 확인 | 6 | 공문·시스템·메일 3분기 × 앱 2종에서 제시한 초안에 대한 실제 사용자 확인 |
| 전달·검토 흐름 | 14 | 7변형 × 앱 2종: 외부 복사 끔/성공/부분 실패/충돌/재실패/미확인 초안/사람 거절. 실제 앱 승인·검토 기록 필요 |
| 배포 권리 및 패키지 | 5 | 권리 게이트 1행, 허가된 구·신 패키지가 필요한 업데이트/제거 4행 |
| 합계 | **63** | 같은 기능의 앱별·조건별 시험이 각각 한 행임 |

Hwp_doc에서 미충족 집계의 단순 미실행·외부 PC 제외 누락을 정정했다. 원래 평가 및 후속 실행 근거는 변경하지 않았다.
