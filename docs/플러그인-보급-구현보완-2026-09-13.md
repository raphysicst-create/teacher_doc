# 플러그인 보급 구현 보완

기존 구현 결과에 이어, 외부 컴퓨터 시험을 제외한 구현 목표를 계속 진행한 기록이다. **전체 목표 완료 선언은 아직 하지 않는다.** 기존 구현 결과의 69개 시험·이관 조사만 수행·설치 미검증 설명은 아래 결과로 보완한다.

## 구현 보완

- 코드 업데이트만 발생했을 때 문안의 재승인을 요구하던 경로를 수정했다. 기존 manifest/승인 해시는 그대로 두고 검증 도구 해시 변경을 tool_updates에 남긴다. status는 이전 검증을 무효화하고 validate가 전체 검사를 다시 수행한다. 원문이나 승인 입력이 바뀌면 이 경로를 사용할 수 없다.
- setup-hooks에 소유 기록, 변경 전 설정 백업, 이전 설치 경로 교체, --remove 제안/적용을 추가했다. 소유 기록과 정확히 일치하는 항목만 처리하고 다른 훅·사용자 설정·교사 파일·PC 환경은 보존한다. 사용자가 수정한 관리 항목은 덮어쓰지 않는다.
- 기존 5종을 `.hwpdoc/templates/<양식>/legacy-1`의 실제 등록 초안으로 이관했다. 원본 사본·기계 슬롯 매핑 제안·과거 slots/budget/structure/README 사본을 보관했다. 과거 프로파일은 legacy 하위에 두고 새로운 검증 근거로 사용하지 않는다. 실제 사람 등록 확인 전에는 draft다.
- 등록 양식의 PDF/PNG 검토 근거를 등록 이후에도 다시 해시 대조한다. 이 파일도 문서 작업의 검증 의존성에 넣어 변경/삭제 후 과거 pass를 배달할 수 없게 했다.
- add-template --review-draft와 hwpdoc_preview.py를 추가했다. 필요한 한글 PDF 내보내기·원문 대조·전체 페이지 PNG를 준비하고 미승인 검토 JSON을 만든다. confirmed는 false, by/at/record는 비어 있다. 실패나 미확인을 실제 확인으로 승격하지 않는다.
- 정상 XML의 주석/처리 지시문 때문에 page_guard 구조 지문 생성이 실패하던 오류를 수정했다. 주석을 삭제하거나 검사를 꺼서 해결하지 않고 지문에 보존한다.
- render_check는 --keep-pdf 사용 시 불필요한 전역 임시 폴더를 만들지 않는다. 임시 PDF가 필요하면 교사 작업 폴더 tmp에 둔다.
- 배포 변경 이력과 새 스크립트를 허용 목록에 반영했다. 실제 배포 권리 미확인 차단은 유지한다.

## 로컬 실동작 증거

현재 PC의 별도 Python 3.12.10 가상환경에 설치 스크립트로 기본/Windows/학교 자료/시각 의존성 8개를 설치했다. pip check가 통과했다. 이 시험에서는 기존 고정 Python에서 파생된 아래 별도 인터프리터를 의도적으로 사용했다. 기존 PC runtime.json은 변경하지 않았다.

`C:/Users/22/Desktop/maintain/Hwp_doc/.claude/scratchpad/install-check-f0d192c225474ac1a5b9a4db25bf1f7a/runtimes/0.1.0-base-school-visual/Scripts/python.exe`

같은 격리 경로의 `교사 작업 폴더`에서 init과 doctor를 실행했다. 패키지와 한글 보안모듈 등록 진단이 통과했다. 한글 버전은 `13, 0, 0, 3903`으로 관측됐다. 실제 앱 스킬 로딩·훅 신뢰·앱별 차단은 unverified로 유지했다.

운영 원본 대신 생성한 합성 HWPX의 등록 기계 단계를 실제 실행했다. `synthetic-unique-form/1`은 구조·네임스페이스·finalize·layout·프로파일·한글 열기·PDF 대조·PNG 생성이 통과했다. 결과와 기준 문서는 모두 1쪽이며 26개 앵커의 발견율과 순서 비율은 1.0이었다. 생성 PNG를 직접 읽어 문단 1~26이 보이며 페이지 내부에 배치됨을 확인했다. **개발자의 합성 문서 확인이며 실제 사용자 양식 등록 승인은 아니다.** review.draft.json은 confirmed=false, 등록은 awaiting_review로 남겨 두었다.

증거 위치:

`.claude/scratchpad/install-check-f0d192c225474ac1a5b9a4db25bf1f7a/교사 작업 폴더/.hwpdoc/templates/synthetic-unique-form/1/`

동일 문장만 반복한 별도 합성 문서 `synthetic-form/1`은 고유 앵커가 없어 render_check가 unconfirmed였다. 이 결과를 통과로 바꾸거나 검사 기준을 낮추지 않았다. 서로 다른 문단을 가진 위 양성 시험과 별개의 음성 사례로 남긴다.

개발 회귀시험은 80개가 통과했다. 이는 외부 컴퓨터 시험이나 두 앱의 실제 인수를 대체하지 않는다. 운영 학교의 신규 승인/검토 로그로도 옮기지 않았다.

## 계속 확인할 항목

- 실행 환경/의존성 버전 변경 후 기존 검증 신선도와 doctor 진단을 더 엄밀히 대조할 것.
- 등록·업데이트·배포 전체 입력 계약과 계획의 나머지 항목을 완료 근거별로 재감사할 것.
- 실제 앱 인수는 별도 평가 범위와 조율하고, 외부 컴퓨터 시험은 이번 사용자 목표에서 제외할 것.
- 원본·자산·업스트림의 재배포 권리 확인과 실제 사람 등록 확인을 자동 생성하지 말 것.

커밋·푸시·공개 배포는 수행하지 않았다. 별도 평가 패키지를 수정하거나 평가 명령을 실행하지 않았다.
