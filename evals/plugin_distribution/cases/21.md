# 21. 신규 환경 설치와 선택 의존성

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `base_only` / `kordoc_enabled` / `no_hancom` / `security_module_missing` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: fresh_environment, release_candidate (fixtures.json의 실제 파일로 제공)

선택 앱의 신규 환경에서 variant에 맞춰 설치·doctor·기본 읽기를 수행하세요. 계정이나 보안모듈 등록이 필요한 경우 평가자가 직접 설정했다고 가장하지 마세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
