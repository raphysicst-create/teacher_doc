# AGPL 소스·고지 준비 검토 — 2026. 9. 13.

검토자: Codex. 사용자 결정: “무료 AGPL 이지 당연히”, 이어 소스 제공·고지 준비에 “해줘”.

## 준비 결과

- teacher_doc 결합 프로그램의 무료 AGPL v3 배포 고지, 상류 MIT 고지, 변경 고지, 소스·설치 안내를 작성했다.
- MuPDF 1.28.0 공식 소스의 COPYING에서 AGPL 전문을 바이트 그대로 가져왔다. GPL-3.0-only 전문도 포함해 PyMuPDF 소스의 개별 표기를 보존했다.
- PyMuPDF 1.28.0 소스 압축본은 PyPI가 제시한 SHA256과 일치한다. MuPDF 1.28.0 소스는 상류 HTTPS 배포 주소에서 직접 받아 해시를 기록했다. 소스 압축본은 수정하지 않았다.
- PyMuPDF setup.py의 MuPDF 고정 버전 1.28.0, 소스·빌드 파일, MuPDF 헤더의 버전 및 thirdparty 소스 포함을 확인했다.
- 대응 소스는 156,561,487바이트의 두 압축본과 편집 가능한 teacher_doc 배포 소스 파일로 제공한다. 루트 SOURCE-BUNDLE.json과 release-inventory.json이 버전·출처·해시를 기록한다.
- 기존 8종 의존성의 원래 라이선스·NOTICE 사본도 배포 허용 목록에 넣었다. 고지의 동봉은 각 의존성의 모든 조건 검토 완료를 뜻하지 않는다.
- 빌드 검사에 필수 고지/소스 누락, 해시 불일치, 버전 불일치, 오래된 소스 검토 해시 차단을 연결했다. 선언을 지워도 PyMuPDF 의존성이 있으면 검사한다.

## 검토 범위

새 고지 파일에는 운영 학교·개인 경로·문서·감사 기록을 넣지 않았다. 외부 소스와 라이선스 사본은 공개 상류 원본이며 로컬 운영 자료를 추가하지 않았다. 출처와 보존 해시는 distribution/source-bundle.json에 기록했다. 외부 소스에 포함된 상류 시험 자료와 개별 고지는 그대로 보존했다.

이번 작업은 소스/고지 제공 준비 검토이며 전체 배포 허가, 원래 운영 자산의 권리·개인정보 검토, 앱 인수 완료를 대신하지 않는다. C++ 전체 재빌드 및 상류 wheel과의 바이너리 동일성 시험은 실행하지 않았다. 의존성 바이너리를 직접 묶는 변경에는 별도 소스 제공 검토가 필요하다.

라이선스 전문은 출처의 재배포 허용 조건에 따라 그대로 복사했다. Canine89 MIT 표준 고지는 사용자 확인에 따라 배포자가 붙인 것이며 개인 허락 원문의 복제본으로 표시하지 않았다.

## 검증

- 배포 관련 회귀시험: `python -B -X utf8 -m unittest discover -s tests -p test_distribution_*.py` — 48개 통과(소스·고지 전용 8개 포함).
- 실제 소스 압축본: SHA256 및 필수 소스·빌드 파일, 버전 대조 통과.
- 실제 전체 허용 목록의 소스/고지 검사 통과. 전체 패키지는 나머지 기존 권리/자산/의존성 검토가 완료될 때 생성한다.
