# 30. 동료 교사 PC의 첫 사용

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `default` 중 하나
- 실행 대상: teacher_selected 중 지정한 하나
- 제공 자료: fresh_environment, native_teacher_form, release_pair (fixtures.json의 실제 파일로 제공)

선택한 앱으로 처음 설치하는 교사가 자기 양식 등록부터 문서 작성·한글 검토·업데이트까지 진행하도록 안내하세요. 모르는 설정과 어려웠던 지점을 기록해주세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
