# 31. 성능 실측과 검증 캐시 정합

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `timing` / `unrelated_change` / `artifact_change` / `validator_change` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: job_seed (fixtures.json의 실제 파일로 제공)

같은 입력·환경에서 단계별 시간을 측정하고 variant에 따라 무관 자료 또는 결과/검증 도구만 바꿔 상태를 확인하세요. 임의 속도 목표는 만들지 마세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
