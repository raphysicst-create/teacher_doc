- w1/w2 요구사항을 CLAUDE.md와 대조·이관한 뒤 별도 스킬을 제거했다. 업무 분기와 검토 로그 W1/W2 값은 유지한다.

- scripts/hwpdoc.ps1 및 hwpdoc.py에 doctor/build/validate/deliver/status를 추가했다. 승인 입력과 파일 해시, 단계 상태, 실패 횟수, 근거 기록, 공유값, 초안/검증완료본 구분, OneDrive 복사 재시도를 처리한다.
- .agents/skills/hwpx는 .claude/skills/hwpx를 가리키는 링크다. 정본과 해시는 `20fe9afebb71889eb5f4d2ed15fbcdb364696fcab008e3cc02cedfbde9e4c4d7`로 일치했다.
- 기존 Codex fallback/루트 마커를 유지했다. 부모 지침을 가리는 파일은 발견되지 않았다. 합계 33,021바이트로 기본 32KiB를 넘으므로 프로젝트 읽기 한도를 64KiB로 설정했고 실제 앱 엔진 config/read에서 확인했다.
- Codex 패치·셸·MCP 이벤트 어댑터와 감사·종료 훅을 추가/수정했다. PowerShell 래퍼의 차단 종료코드 2 보존도 직접 검사했다.
- 같은 호스트의 school_task_guide 설정을 보존하고 kordoc의 기존 설정을 .codex에 연결했다. 자동 가져오기·별도 서버 설치는 하지 않았다.

## 남은 인수

1. 프로젝트의 `/hooks`에서 .codex/hooks.json의 PreToolUse/PostToolUse/Stop 정의를 검토·신뢰한다. 현재 신뢰되지 않아 호스트가 실행을 보장하지 않는다. 신뢰 우회 플래그는 사용하지 않았다. [공식 훅 신뢰 절차](https://learn.chatgpt.com/docs/hooks)
2. 해당 프로젝트를 로컬 Work와 Codex Sol High에서 각각 열어 실제 지침/스킬 본문 경로·내용 해시·앱 버전을 기록하고, 가짜 파일의 실제 사전 차단과 파일 불변을 다시 확인한다.
3. 같은 입력·모델·도구로 스킬 정리만의 전후 비교를 수행한다. 실행기 도입 효과와 분리한다.
4. 대표 6건 × 두 환경 × 3회 = 36회를 실제 수행하고 사람 문안/레이아웃 비교를 기록한다. 현재 인수 장부는 **0건 통과 / 36건 미검증**이다. 미실행을 실패 0건 달성으로 해석하지 않는다.

직접 셸의 동적 경로·별도 스크립트·자식 프로세스 전체 보호는 미지원이다. 실행기 절차, 도구 훅, 파일시스템 권한은 별개이며 훅을 완전한 보안 경계로 간주하지 않는다. 기존 수동 편집·검증 경로는 유지한다.
