# 32. HWP 변환·재패키징·폴백 경로

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `hwp_input` / `repackaged` / `fallback_absent` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: converted_fixture (fixtures.json의 실제 파일로 제공)

제공한 시험 원문을 보존하면서 HWPX 검토본을 준비해주세요. 입력 출처와 변환 여부를 밝히고, 주력 경로를 사용할 수 없으면 실제 지원하는 복구 경로를 설명해주세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
