# teacher-doc-schoolinfo 변경 기록

## 0.1.0 — 2026-09-18

schoolinfo-mcp 0.3.0의 소스를 teacher_doc에 통합한 축소본이다. 기준 커밋과 출처는 UPSTREAM.json, 원래 MIT 고지는 LICENSE에 있다.

- 학사일정, 교육과정, 교수학습 평가계획, 자유학기 운영계획서 4개 도구로 줄였다.
- AI가 대화·기존 작업 설정에서 알아낸 학교명을 자료 조회 인수로 전달하고 서버가 공개 검색으로 식별한다. 동명이교는 선택 인수로 구분하며 별도의 학교 고정 설정이나 검색 도구를 요구하지 않는다.
- 학교 기본정보·학생/학급 수·통계와 학교알리미 OpenAPI 키 의존을 제거했다. 학사일정은 NEIS API 키를 사용한다.
- 급식·주간 브리핑·오늘 시간표·입시·학교 비교·일반 공시·로컬 파일 도구와 웹앱·범용 CLI·기존 호스팅 설정을 제거했다.
- stdio와 HTTP가 같은 도구 구현을 사용한다. HTTP는 /mcp와 /health만 제공한다.
- 연도와 평가계획 학기를 명시하고, 학교와 첨부가 모호하면 후보를 반환한다. 자유학기 계획은 같은 연도에서 첨부가 있는 가장 최근 공시 회차를 조회한다. 전체 문서와 표를 반환하고 원본 다운로드 URL·SHA-256·제출 회차를 기록한다.
- 파싱 실패·자료 없음·API 오류를 미확인으로 반환한다. 원문·파일명·출처 속 학교명은 보존하고 별도의 학교정보 객체는 반환하지 않는다.
- 기준 체크아웃의 이전 변경 기록은 https://github.com/raphysicst-create/schoolinfo-mcp/blob/180019e38cb35cf9b66aae32607a1da2ee41db24/CHANGELOG.md 에서 확인할 수 있다.
