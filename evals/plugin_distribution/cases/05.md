# 05. Python 진단과 외부 복사 선택 설정

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `valid_python` / `missing_python` / `wrong_python` / `copy_disabled` / `copy_configured` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: isolated_pc (fixtures.json의 실제 파일로 제공)

격리한 PC 설정으로 각 variant를 진단하세요. 실제 계정 설정·PATH·레지스트리는 변경하지 마세요. 복사 위치는 시험 폴더만 지정하세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
