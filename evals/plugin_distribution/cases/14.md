# 14. 메모리 없이 학교 정책·공통 규칙 유지

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `precedent` / `empty_cells` / `grade_absent` / `metadata` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: policy_fixture, native_notice (fixtures.json의 실제 파일로 제공)

가상학교 설정과 양식을 따라 variant의 문서를 검토해주세요. 이 세션에는 과거 프로젝트 메모리가 없습니다. 설정의 교사 선택을 존중해주세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
