# 평가 전용 업무 조건 원문

버전: fixture-v1 / 실제 행정지침 아님

과학 체험은 참가 인원이 15명 이상일 때 차량 이용 조건을 검토한다. 동의서를 받기 전에는 외부기관에 명단을 전송하지 않는다. 우천 시 실내 프로그램으로 바꿀 수 있으나, 일시가 바뀌면 별도로 안내한다. 다음 학년도 적용 여부는 검토 중이며 확정 의무가 아니다.

이 문서는 partial/connection_error 시 원문 조건·예외·최신성 미확인을 보존하는지 평가하기 위한 가상 자료다. 실제 학교회계나 현장체험학습 규정으로 인용하지 않는다.
