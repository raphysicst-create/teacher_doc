## 동작 계약

- 진입점은 `scripts/hwpdoc.ps1 --workspace <작업 폴더> <명령>`이다. 기존 doctor/build/validate/deliver/status도 유지한다. `--workspace`는 서브명령 앞에 둔다.
- 설치 코드와 교사 자료를 분리한다. 신규 설정은 `.hwpdoc/workspace.json`, 현재 운영 학교 호환 설정은 `config/legacy-workspace.json`, PC 설정은 `%LOCALAPPDATA%/hwpdoc/runtime.json`이다. 학교 자료가 없는 업무만 자료를 요청한다.
- init은 선택한 앱의 짧은 지침을 만든다. 기존 지침은 보존하고 병합 제안을 별도 저장한다. 현재 Hwp_doc와 maintain 부모에 AGENTS.md를 만들지 않는다.
- add-template은 source→mapping→review 단계다. 원본을 먼저 추출하여 읽을 수 있는지 확인하고 사본을 만든다. 구조→네임스페이스→finalize→layout→프로파일→한글 검증 후 실제 사람 확인 기록을 수리한다. 원본 종류·용도·파일 해시와 확인 기록을 연결한다. 등록 완료 뒤 수정은 새 version을 사용한다.
- prepare는 상대경로의 원문 사본, 해시, 슬롯, 환경과 미확인 항목을 준비한다. 실제 승인·근거 해석·육안 확인은 만들어 넣지 않는다. 등록 양식의 용도와 원본 종류를 입력에 대조한다.
- v2 입력은 원문/첨부/evidence/source/reference의 현재 해시를 요구한다. 초안 승인 해시는 draft_approval를 제외한 입력 전체의 정렬 JSON 해시다. 이동 때문에 과거 승인을 다시 작성하지 않는다.
- 보고서의 실행 경로는 `workspace:`/`plugin:` 기준으로 저장하며 v1 절대경로 기록도 읽는다. 과거 명령의 진단 문자열과 원문 출처는 역사 기록이므로 옛 경로가 남을 수 있다.
- workspace COM 잠금과 동일 단계 2회 실패 중단을 유지한다. 여러 앱/작업 폴더의 COM 공유 잠금은 추가하지 않았다.
- setup-hooks는 먼저 제안 파일을 만든다. `--apply`는 기존 등록을 보존해 병합한다. 과거 설치 경로 항목의 자동 제거·훅 신뢰 승인은 하지 않는다. 등록·신뢰·실제 차단은 별도 증거다.
- Stop은 새 작업 폴더 첫 실행부터 변경 산출물을 검사한다. 기존 운영 폴더의 최초 기준선은 `ok: null`, `unconfirmed`이고 전체 검증 완료 근거가 아니다. 시간 초과·미검사 경고도 사용자에게 전달한다.
- 외부 복사 미설정은 not_applicable이다. 현재 학교 OneDrive 동시 복사 정책은 호환 설정에서 유지한다. 사람 최종 검토와 사람 발송은 그대로다.

상세 사용 안내와 첫 지원 학교 자료 형식은 `distribution/README.md`, 공통 업무 절차는 `.claude/skills/hwpx/references/workflow.md`에 있다.

## 배포 보류 사유

배포 점검 결과는 blocked다. 67개 파일의 재배포 권리와 개인정보 검토 기록, 의존성 8개의 조건 확인 기록이 아직 없다. 자동 검색의 현재 사용자 경로·학교명 패턴 검출은 0건이지만 Preview·이미지·메타데이터의 익명성을 증명하지 않는다. 따라서 설치 가능한 배포본을 만들지 않았다.

조사 시 [Canine89/hwpxskill 저장소](https://github.com/Canine89/hwpxskill)의 GitHub API license 값은 null이고 루트 파일 목록에 LICENSE가 없었다. 재배포 허용 조건을 확인하지 못했다는 뜻이며 임의 라이선스를 부여하지 않았다. [PyMuPDF](https://pymupdf.readthedocs.io/en/latest/about.html)는 AGPL/상용 조건 검토 대상이다. 현재 프로젝트 자체 코드와 포함 기본 자산도 검토가 필요하다. 기록 양식은 `distribution/rights.pending.json`이다.

Python 의존성은 개발 환경에서 관측한 lxml 5.4.0, python-hwpx 2.23.0, pypdf 6.14.2, pywin32 312, openpyxl 3.1.5, et-xmlfile 2.0.0, xlrd 2.0.2, PyMuPDF 1.28.0으로 고정했다. 기본/Windows/학교 자료/시각 의존성을 분리했고 깨끗한 PC 설치 성공은 미검증이다.

원격 origin은 확인했으나 공개 여부/접근 권한은 확인되지 않았다. 커밋·푸시·공개 저장소 생성·현재 플러그인 재설치를 수행하지 않았다.
