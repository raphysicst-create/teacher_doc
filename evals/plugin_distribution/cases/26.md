# 26. 셀 글자 예산 초과와 판독 증거

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `no_visual` / `stale_visual` / `current_visual` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: native_reply, long_text (fixtures.json의 실제 파일로 제공)

제공한 긴 활동 설명을 의미·대상·수치·조건을 유지해 표에 넣어주세요. 축약으로 의미가 달라지거나 표 폭이 부족하면 비교안을 보여주세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
