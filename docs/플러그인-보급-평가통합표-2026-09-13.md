# 플러그인 보급 평가 통합표 — 2026. 9. 13.

최초 독립 평가 176행에 결함 수정, 115행 후속 분류, 분류 정정, 기존 자료 활용 시험을 합쳤다. 이번 작업은 표 통합이며 새 시험 실행이나 독립 점수 재채점이 아니다. **이 표의 현재 상태를 최신 통합 기준으로 사용한다.** 이전 표/점수/원시 기록은 보존했다.

최초 독립 점수는 **합격 56 / 실패 3 / 미실행 2 / 차단 115** 그대로다. 최초 실패 3행은 두 결함을 수정해 후속 확인했으며, 원래 실패 기록을 삭제하지 않았다. 과거 합격 56행은 최신 수정본 전체 재검증을 뜻하지 않는다.

**후속 작업이 남은 행은 72개**(부분 확인 13 + 자료 확보·후속 대기 26 + 선행 조건 대기 29 + 미실행 4)다. 각 앱/조건별 시험 행의 수이며 서로 다른 결함 72개나 사람 승인 72회를 의미하지 않는다. 배포는 계속 보류다.

## 변경이 반영된 방식

- 최초 차단 115행 → 동작 확인 36, 부분 확인 13, 자료 확보·후속 대기 26, 선행 조건 대기 29, 미실행 2, 제외 9. 합계 115.
- 기존 66건 중 무표시 cwd 시험 2건은 미실행으로, 동료 교사 PC 1건은 제외로 정정했다.
- 자료 부족 34행 → 자료 확보·후속 대기 26, 기안문 계보 부분 확인 4, 행 부족/판독 없는 예산 초과의 실제 동작 확인 4로 반영했다. 34개를 일괄 합격시키지 않았다.
- `19 clean/sentinel_leak`은 최초부터 남았던 미실행 2행이다. 실제 릴리스 ZIP 및 시험이 없고 당시 stale 표시도 유지한다.
- 기존 학교 자료를 사용하는 로컬 후속 시험과 최초 가상학교/격리 설치 조건을 구분한다. 새 승인이나 사람 판독을 만들지 않았다.
- HWP 변환 원문자 경고 FAIL과 원본·변환본 7쪽 픽셀 동일 관측을 함께 보존했다. Codex 묶음 시험 300초 종료 및 같은 세션의 보고서 완성 이력도 보존했다.
