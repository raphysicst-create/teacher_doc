# 06. 학교별 시간표·예산·관련번호 조회

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `timetable` / `budget` / `related` / `missing_sources` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: school_alpha, school_beta (fixtures.json의 실제 파일로 제공)

가상 가람중/누리중 자료를 각각 조회하세요. 학년 구성·과목·문서 접두어·연도가 다른 두 학교를 구별하고, 자료 없는 경우를 별도로 실행하세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
