# 변경 이력

## 0.1.0 구현 중 — 미배포

- 프로젝트·플러그인·배포 폴더 이름을 teacher_doc으로 변경. teacher_doc CLI 추가, 기존 hwpdoc 실행기와 저장 형식 호환 유지.

- 설정/등록 형식 v1, 준비 입력 v2, 보고서 경로 형식 v2. 기존 절대경로 보고서를 읽는다.
- 코드·교사 작업 폴더·PC 환경 분리. 현재 학교 설정과 기존 양식 5종 호환 유지.
- 신규 양식 등록과 기존 양식 등록 초안 이관. 원본·의미 매핑·용도·검토 해시 연결.
- W1/W2 공통 업무 절차와 앱별 초기 안내문. 미확인 입력과 실제 사람 확인을 구분.
- 코드 업데이트 후 기존 문안 승인을 유지하고 전체 검증 재실행. 원문/입력 변경은 별도 확인 필요.
- 훅 소유 기록을 이용한 업데이트/제거, 변경 전 설정 백업. 다른 훅·교사 자료·PC 환경 보존.
- 배포 허용 목록과 파일별 권리/개인정보 검토, 의존성 조건 검토 차단.
- Python·패키지 변경도 검증 신선도에 반영. doctor의 실제 import·고정 버전 검사.
- 운영 원본을 보존한 기본 자산 익명화 후보, 메타데이터 잔재 검사, 복사 완료 후 패키지 확정.
- 설치에 폴백이 없는 경우 실제 제공 가능한 새 사본 복구 경로 안내.
- init의 Windows 경로 길이 사전 진단과 기존 양식 prepare의 미입력 슬롯 목록 보완.
- Windows 실제 호스트에서 발견한 훅 경로 인용·시작 지연·차단 종료코드 전달 문제 보완. 업데이트 후 setup-hooks --apply 및 Codex의 변경된 훅 신뢰 확인 필요.
- Claude Bash의 PowerShell 단일 원본→새 출력 복사 지원. 셸 확장·덮어쓰기·복합 명령은 허용하지 않음.
- Windows PowerShell 런타임 오류를 UTF-8로 출력해 한국어 진단 깨짐 방지.

개발 회귀시험과 실제 앱 인수는 별도다. 아직 외부 컴퓨터 시범 사용 및 배포 권리 확인을 완료하지 않았다.
