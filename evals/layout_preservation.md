# 기존 양식 편집 — 판단 회귀 사례

2026. 9. 12. 평가계획 비교에서 확인한 실패를 다시 점검하는 운영자용 사례다. 기존 workflow_5의 회차·점수와 별개이며, 아래 기대 판단을 읽은 작성자의 자기 점검을 독립 모델 실행이나 사용자 승인으로 세지 않는다.

## 실행·판정

- 실제 모델 평가 시 새 작업에서 현재 CLAUDE.md·hwpx 스킬과 해당 사례 입력만 제공한다. 이전 결과와 이 문서의 기대 판단은 최초 응답 고정 전 작성자에게 제공하지 않는다.
- HWPX 생성까지 시험하려면 학교 실무 원본 대신 표 구조·서체가 있는 합성 양식과 가상 값을 프로젝트 스크래치패드에 준비한다. 생성 전 실제 사용자 초안 확인 절차는 유지한다. 자동 응답으로 승인을 만들지 않는다.
- 요청·지침 해시·모델/추론 설정·도구·권한·추가 지시를 구분해 기록한다. 도중 조건을 바꾸었다면 한 변수만의 효과로 결론내리지 않는다.
- 판단은 출력 초안·선택 베이스·슬롯 매핑·구조 비교·렌더·사용자 원문으로 평가한다. 단어가 지침에 들어 있다는 이유로 통과시키지 않는다. 미실행은 pending이다.

## 생성까지 진행한 경우의 완료 근거

문안 확인과 구조 변경 승인 원문을 구분한다. 원본/결과의 제목 서식·상자·표 구성·여백·명의 위치를 대조하고, 구조 차이는 승인 범위와 일치해야 한다. 예산 초과 사본은 먼저 미검증으로 렌더·판독한 뒤 최종 편집한다. 판독 사본과 최종 파일 해시가 다르면 최종 파일을 다시 렌더한다. 공통 Validator와 신구대조, 재시도 2회 한도는 그대로 적용한다. 이 과정은 HWPX 기술 검사와 문서 품질을 함께 평가하며 사용자 5점 평가를 대신하지 않는다.
