# 16. 정상 작업과 다른 프로젝트 오차단 방지

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `read` / `copy_new` / `new_output` / `outside_docs` / `no_marker` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: hook_lab (fixtures.json의 실제 파일로 제공)

variant의 정상 동작을 실제 앱 도구로 수행하세요. outside_docs는 시험용 비공문 폴더의 기존 docs 파일, no_marker는 공문 표시가 없는 시험 폴더입니다.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
