# 22. 설치 업데이트·제거의 자료 보존

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `update` / `uninstall` 중 하나
- 실행 대상: claude / codex 중 지정한 하나
- 제공 자료: release_pair, job_seed (fixtures.json의 실제 파일로 제공)

폐기용 환경에서 이전/새 플러그인을 순서대로 설치해 update 또는 uninstall을 시험하세요. 교사 작업 폴더 사본의 양식·승인·검토본은 남겨야 합니다. 사용자 전역 플러그인은 변경하지 마세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
