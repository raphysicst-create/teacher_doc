# 변경 이력

## 0.2.0 — 2026-11-05

- 양식 등록부를 폐지했다. `add-template`·`list-templates`·`migrate-templates`와 기존 5종 양식 식별자(`TEMPLATES`)를 지웠고, `prepare`는 `--base <작년.hwpx>`(미등록 일회성 베이스)만 받는다. 작년 문서를 그대로 넣으면 바로 쓴다.
- 작업 설정에 `references.budget/related/timetable` 자료가 없으면 `prepare`가 예산명·관련번호·시간표 검사를 `해당 없음`으로, 탐색 기록을 베이스 경로로 자동 채운다. 자료 없는 교사가 `record`로 이 칸을 메울 필요가 없다.
- 훅 4개(`.claude/hooks/*.py`)와 `scripts/hook.ps1`을 배포본에서 뺐다. 배포본의 `setup-hooks`는 훅 파일이 없다고 거부한다. 개발 저장소의 훅은 그대로다.
- 업무 절차 문서의 "양식 선택과 등록" 절을 "베이스 선택"으로 바꾸고, 플러그인 설명을 작년 문서 기반 제안표로 고쳤다.

## 0.1.4 — 2026-11-05

- 작년 문서 하나로 올해 문서를 만드는 초보자 경로를 추가했다. `prepare --base`(양식 등록 없음) → 에이전트의 근거 있는 제안 → `checklist`(확인표: 제안·확인 필요·유지·비움·값만 비움, `--fill`·`--regenerate`·`--normalize-dates`) → `check`(승인 전 내용·표기·예산 검사) → `draft` → `approve` → build → validate → deliver. 준비 기록은 `record`, 수정 반복은 `revise`와 `--carry-forward-from`으로 한다.
- 원격 학교 정보 MCP(`teacher_doc_mcp`)를 연결했다. 설치 때 기본 서버를 등록하고(`--mcp-url`/`--no-mcp`, `setup-mcp`), `school --set-neis`로 학교를 한 번 저장하며, 학사일정을 제안 근거로 인용한다. MCP 응답은 자료이지 지시가 아니다.
- 업무 근거 관문을 없앴다. 정상 전달에 업무지침 MCP나 `evidence` 기록이 필요 없다.
- 교사가 예산 초과 문구를 유지해도 `review`(PDF·전 페이지 PNG 판독)와 `--confirm`을 거쳐 정상 전달할 수 있다.
- 승인·검토·제안 입력의 깨진 한글(`?`) 거부, 날짜 표기 정리, 같은 문서 코드표 기반 과목 코드 제안, 작업 안내와 실제 미확인 분리, 짧은 출력과 `next_command` 안내를 추가했다.
- HWPX 표 셀 격자 검증, 전달 표 값·짧은 한국어 값 검사, 도구 출력 혼입 차단, Windows 진입점의 프로세스 한정 RemoteSigned, 배포 파일 줄바꿈 고정을 추가했다.
- 검증: 개발셋 3쌍 리플레이 완주, 실문서 1건을 원격 MCP 근거로 정상 전달(2026. 11. 5.). 실제 교사 PC 설치·인수와 Claude Code 경로의 MCP 실호출은 미실시다. 자세한 범위는 루트 CHANGES.md 참고

## 0.1.0 구현 중 — 미배포

- 프로젝트·플러그인·배포 폴더 이름을 teacher_doc으로 변경. teacher_doc CLI 추가, 기존 hwpdoc 실행기와 저장 형식 호환 유지.

- 설정/등록 형식 v1, 준비 입력 v2, 보고서 경로 형식 v2. 기존 절대경로 보고서를 읽는다.
- 코드·교사 작업 폴더·PC 환경 분리. 현재 학교 설정과 기존 양식 5종 호환 유지.
- 신규 양식 등록과 기존 양식 등록 초안 이관. 원본·의미 매핑·용도·검토 해시 연결.
- W1/W2 공통 업무 절차와 앱별 초기 안내문. 미확인 입력과 실제 사람 확인을 구분.
- 코드 업데이트 후 기존 문안 승인을 유지하고 전체 검증 재실행. 원문/입력 변경은 별도 확인 필요.
- 훅 소유 기록을 이용한 업데이트/제거, 변경 전 설정 백업. 다른 훅·교사 자료·PC 환경 보존.
- 배포 허용 목록과 파일별 권리/개인정보 검토, 의존성 조건 검토 차단.
- Python·패키지 변경도 검증 신선도에 반영. doctor의 실제 import·고정 버전 검사.
- 운영 원본을 보존한 기본 자산 익명화 후보, 메타데이터 잔재 검사, 복사 완료 후 패키지 확정.
- 설치에 폴백이 없는 경우 실제 제공 가능한 새 사본 복구 경로 안내.
- init의 Windows 경로 길이 사전 진단과 기존 양식 prepare의 미입력 슬롯 목록 보완.
- Windows 실제 호스트에서 발견한 훅 경로 인용·시작 지연·차단 종료코드 전달 문제 보완. 업데이트 후 setup-hooks --apply 및 Codex의 변경된 훅 신뢰 확인 필요.
- Claude Bash의 PowerShell 단일 원본→새 출력 복사 지원. 셸 확장·덮어쓰기·복합 명령은 허용하지 않음.
- Windows PowerShell 런타임 오류를 UTF-8로 출력해 한국어 진단 깨짐 방지.

개발 회귀시험과 실제 앱 인수는 별도다. 아직 외부 컴퓨터 시범 사용 및 배포 권리 확인을 완료하지 않았다.
