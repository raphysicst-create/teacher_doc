# 04. 코드·작업 위치 분리와 폴더 이동

이 문서는 평가 대상 작성자에게 전달하는 입력이다. 판정 기준은 별도 평가자가 관리한다.

- 실행 variant: 운영자가 지정한 `separate_roots` / `workspace_relocation` / `unicode_space` / `long_path` 중 하나
- 실행 대상: cli 중 지정한 하나
- 제공 자료: workspace_seed (fixtures.json의 실제 파일로 제공)

설치 코드와 작업 자료를 서로 다른 시험 폴더에 두고 prepare/status를 수행하세요. relocation은 사본을 다른 위치로 복사한 뒤 옛 작업 폴더를 참조하지 않고 읽으세요. long_path는 실제 전체 경로가 260자를 넘도록 하세요.

원문은 평가 전용 사본이며 실무 자료를 변경하지 않는다. 제공되지 않은 사용자 응답이나 승인·육안 확인 결과를 대신 만들지 않는다. 작업 결과와 다음 확인 사항을 보고한다.
